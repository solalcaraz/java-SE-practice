# Java SE – Práctica (**[Todo Code Academy](https://todocodeacademy.com/)**)

Repositorio con ejercicios prácticos e integradores realizados durante el curso **“Java para Principiantes”** de Todo Code.
El objetivo de este repositorio es reforzar y documentar los fundamentos del lenguaje Java y la Programación Orientada a Objetos mediante práctica progresiva.

---

## Contenidos

- Fundamentos de Java
  - Variables y tipos de datos
  - Estructuras de control
  - Bucles
- Programación Orientada a Objetos
  - Clases y objetos
  - Encapsulamiento
  - Herencia y polimorfismo
- Colecciones
- Manejo de excepciones
- Archivos
- Ejercicios integradores

---

## Tecnologías utilizadas

- Java 21 (LTS)
- IntelliJ IDEA
- Git & GitHub

---

### Notas

Este repositorio forma parte de un proceso de aprendizaje y práctica. Los ejercicios integradores cuentan con mayor estructura y organización que los ejercicios individuales.
